# AI Miniature Repainting Desktop Application

This repository contains the early scaffolding for the AI miniature repainting
application described in [`docs/TECHNICAL_STACK_DEFINITION.md`](docs/TECHNICAL_STACK_DEFINITION.md).
The project combines a Tauri desktop shell, a React + TypeScript front-end styled
with Adobe React Spectrum, and a Python sidecar backend that will eventually host
ComfyUI and Diffusers inference pipelines.

## Project Layout

```
ai-miniature-repainting-desktop-app/
├── src/                     # React + React Spectrum UI
│   ├── components/          # Layout shell and feature panels
│   ├── hooks/               # Front-end state management utilities
│   ├── services/            # IPC wrappers for Tauri commands
│   └── styles/              # Global styling entry points
├── src-tauri/               # Rust layer and Tauri configuration
│   ├── src/
│   │   ├── commands.rs      # Exposed commands for the UI
│   │   ├── python_bridge.rs # PyTauri bridge scaffolding
│   │   └── lib.rs           # Tauri builder setup
│   └── tauri.conf.json      # Window + bundler configuration
├── python/                  # Python backend placeholders
│   ├── inference.py         # High level orchestration facade
│   ├── comfyui_wrapper.py   # ComfyUI integration stubs
│   ├── diffusers_wrapper.py # Diffusers fallback stubs
│   └── prompt_builder.py    # Prompt normalisation helpers
└── models/                  # Placeholder directory for large model assets
```

## Getting Started

Install the dependencies and run the Tauri development server:

```bash
npm install
npm run tauri dev
```

### App Icons

To keep the repository binary-free for easier code review tooling, the platform-
specific icon set generated by `tauri icon` is **not** checked into version
control. When you need runnable bundles, generate the icons locally from a base
SVG using:

```bash
npx @tauri-apps/cli icon ./path/to/base-icon.svg
```

This will recreate the `src-tauri/icons/` directory that is ignored by Git.

The current implementation mocks the bridge to the Python runtime while emitting
progress events so the React UI can be developed in parallel with the ML stack.
